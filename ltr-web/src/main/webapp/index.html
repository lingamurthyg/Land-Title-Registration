Land Title Registry System

Ministry of Lands  ·  IBM WebSphere Application Server 9.x  ·  Java 8 / Maven

Technology Stack

WAS 9.x EJB 3.x CMT JNDI DataSource WAS SessionContext ibm-ejb-jar-bnd.xml UOWManager ibm-web-bnd.xml JAAS/LDAP Auth

API Endpoints

📋 Title Registration

Register new land parcels into the national registry.

POST/api/titles
GET/api/titles/{titleNumber}
GET/api/titles?owner={nationalId}
PUT/api/titles/{titleNumber}

🔍 Title Search

Search the registry by status, owner, or keyword.

GET/api/titles?q={keyword}
GET/api/titles?status=ACTIVE
GET/api/titles?status=PENDING
GET/api/titles?status=ENCUMBERED

🔄 Ownership Transfer

Initiate and approve/reject title transfers with full audit trail.

POST/api/transfers
GET/api/transfers?title={num}
POST/api/transfers/{id}/approve
POST/api/transfers/{id}/reject

📊 Supervisor Dashboard

Review and action pending title transfers (SUPERVISOR/ADMIN only).

GET/api/transfers/pending

🩺 Health Check

WAS DataSource and EJB container liveness check.

GET/health

WAS-Specific Blockers (Modernization Assessment)

🔴 ibm-ejb-jar-bnd.xml / ibm-web-bnd.xml

WAS-proprietary JNDI binding files. No equivalent on Open Liberty — must be replaced with server.xml bindings or CDI injection.

🔴 com.ibm.websphere.rsadapter.WSDataSource

IBM proprietary DataSource wrapper. Replace with standard @Resource DataSource on Open Liberty.

🔴 com.ibm.wsspi.uow.UOWManager

WAS Unit-of-Work Manager SPI. Replace with standard JTA UserTransaction or CDI @Transactional.

🟡 Remote EJB over RMI-IIOP

Remote EJBs work on WAS traditional but are unsupported in Open Liberty. Migrate to JAX-RS REST services.

🟡 SessionContext.getCallerPrincipal()

Works on both, but Liberty prefers MicroProfile SecurityContext and MP-JWT for token-based auth.

🟢 EJB 3.x CMT / @Stateless

Fully supported on Open Liberty with ejb-3.2 feature. Low migration effort.
